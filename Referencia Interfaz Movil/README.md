# Referencia de interfaz móvil

Aporte de Cristian Morales como referencia visual para la futura interfaz móvil de HABITA.

- El diseño, las variables y los datos mostrados no corresponden al prototipo actual.
- Las imágenes sirven como guía para organizar las pantallas siguiendo el recorrido: **ubicación → puntaje → explicación**.
- Los datos deberán actualizarse conforme a la versión más reciente del proyecto.
