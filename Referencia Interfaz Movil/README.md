# Referencia de interfaz móvil

Aporte de Cristian Morales como referencia visual para la futura interfaz móvil de HABITA.

- El diseño, las variables y los datos mostrados no corresponden al prototipo actual.
- Las imágenes sirven como guía para organizar las pantallas siguiendo el recorrido: **ubicación → puntaje → explicación**.
- Los datos deberán actualizarse conforme a la versión más reciente del proyecto.

[Ver imágenes de la interfaz móvil](imagenes%20interfaz%20movil/)

## Implementación Android

La versión nativa en Kotlin y Jetpack Compose está en [HABITA_Android](../HABITA_Android/README.md). Mantiene el recorrido móvil del [Figma original](https://www.figma.com/design/nHfZIyxzjzNRKXqNqoWuqX/HABITA?node-id=0-1), adapta sus indicadores a la fórmula actual y utiliza los colores azules y turquesa de las interfaces web del equipo.
