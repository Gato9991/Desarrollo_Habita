# Fuentes climáticas usadas

Se usaron los datos del O₃ y el MP2,5 de las comunas disponibles en [SINCA — Región Metropolitana](https://sinca.mma.gob.cl/index.php/region/index/id/M) para este apartado.

## Primera tanda: 5 archivos CSV

- QUILICURA (DIFERENTE) - 2.5 - 1 YEAR.csv
- ESTACION QUILICURA I - 2.5 - 1 YEAR.csv
- PARQUE OHHINGS - O3 - 1 YEAR.csv
- PARQUE OHHINGS - MP2.5 - 1 YEAR.csv
- TALAGANTE - 2.5 - 1 YEAR.csv

Las dos imágenes adjuntas se conservan en `referencias/`. Se mantienen los nombres originales de los archivos.
